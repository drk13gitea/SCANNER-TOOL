# SCANNER-TOOL
VULNERABILITY ASSESSMENT TOOL
This is a practical VA tool that can be used as a primary tool for basic VA Scan and to understand the device better.

I primarily created this tool with tenable nessus in mind as I used the licensed version of nessus daily at my job and i was really interested in understanding how the tool works and how is it able to perform va scan of a machine in just few hours.

upon performing extensive research and understanding the functionality of the tool I wanted to test the possibility of building one myself just to understand hoe complicated designing a scanner could be and frankly speaking it does not look impossible, the only thing we need would be couple of engineeers and few resources and we can make ours.

I am trying to make this tool fully functional but after spending 9 hours at job i hardly get free time hence the pace of this project would surely be slow, but I will try to keep up at times when possible.
